# BlockPack

*English · [Русский](README.ru.md)*

**Looking for the real project?** → **[simpleitem/BlockPacker](https://github.com/simpleitem/BlockPacker)**

This repository is for **BlockPack**, the graphical interface for
[BlockPacker](https://github.com/simpleitem/BlockPacker). If you arrived here
looking for the modpacking tool itself, its code, its releases or its
documentation, you are in the wrong place — follow the link above.

| You want | Go to |
| --- | --- |
| The modpacking tool (scripts, releases, docs) | [simpleitem/BlockPacker](https://github.com/simpleitem/BlockPacker) |
| The graphical interface (this repo) | You are here |

The graphical interface is in development. Nothing is released yet.
